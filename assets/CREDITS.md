# Artwork sources

- `buzzsave-bee.svg`: the original BuzzSave mascot from https://buzzsave.vercel.app/assets/bee-coach.png, with the PNG bytes preserved inside the SVG. CSS adds a small vertical float and respects reduced-motion preferences.
- `tech/`: Java, Spring, MySQL, Docker and AWS marks from Devicon v2.17.0, https://github.com/devicons/devicon/tree/v2.17.0/icons. The upstream license is retained in `tech/LICENSE`.
- `links/`: static Portfolio, LinkedIn and Email badges downloaded from Shields.io with `style=flat-square`. They use the same badge-row convention as the user's profile references.

Profile composition references: https://github.com/Yaahrit (centered role and mascot) and https://github.com/Shubh2-0 (centered contact links and technology marks). The profile's biography, project descriptions and recognition belong to Rhussel Combo.
