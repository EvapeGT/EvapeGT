# Artwork sources

- `tech/`: Java, Spring, MySQL, Docker and AWS marks from Devicon v2.17.0, https://github.com/devicons/devicon/tree/v2.17.0/icons. The upstream license is retained in `tech/LICENSE`.
- `tech/mysql-dark.svg`: the same Devicon MySQL path with a lighter blue for visibility on dark backgrounds.
- `links/`: static Portfolio, LinkedIn and Email badges downloaded from Shields.io with `style=flat-square`. They use the same badge-row convention as the user's profile references.
- `recognition/umak.png` and `recognition/dict.png`: existing University of Makati and DICT logos from Rhussel's portfolio assets, copied without changing their artwork. The responsive recognition SVGs embed those files unchanged; the AWS lockups embed the Devicon AWS logo. Organization names and marks identify the credential and competition organizers.
- `hello.svg` and `hello-mobile.svg`: original responsive typography for the user's requested greeting.
- `commit-loop.gif` and `commit-loop-still.png`: original geometric Git branch animation authored for this profile. It illustrates branching and merging, rather than actual GitHub contribution data. The static version is used for reduced-motion preferences.

Profile composition references: https://github.com/Fernanda-Kipper (large centered greeting and compact animated introduction), https://github.com/Yaahrit (centered introduction) and https://github.com/Shubh2-0 (contact links and technology marks). The greeting artwork and GIF are original; the profile's biography, project descriptions and recognition belong to Rhussel Combo.
